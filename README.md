# AI Pixel Companion App
این برنامه یک دستیار و دوست پیکسلی هوش مصنوعی با قابلیت چت متنی، لایو صوتی با صدای ژاپنی و زیرنویس فارسی، تشخیص چهره از طریق دوربین، و هوش خودجوش (پروکتیو) است.

### نحوه نصب و استفاده:
1. این فایل‌ها را در گیت‌هاب آپلود کنید.
2. عکس کاراکتر پیکسلی خود را با نام `idle.png` در کنار فایل‌ها قرار دهید.
3. در برنامه وارد بخش تنظیمات شده و کلید API جمنای خود را وارد کنید.
